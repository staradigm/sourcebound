# Contributing to Sourcebound

Thank you for improving Sourcebound.

1. Check existing issues before starting work.
2. Open an issue for substantial behavior or architecture changes.
3. Create a focused branch from `main`.
4. Run `npm test` and `npm run build`.
5. Explain user-visible behavior and test coverage in the pull request.

Keep document contents local by default. New network calls, telemetry, hosted storage,
or model providers require explicit user consent and must be disabled by default.
